## 🚀 核心交互功能

<CardGrid stagger>
  <Card title="🧠 记忆背诵消隐模式" icon="open-book">
    在页面右上角一键开启消隐遮罩，模糊关键犯罪定性、数额等结论词，鼠标悬停即可显现，专为法考背诵记忆设计。
  </Card>
  
  <Card title="🔍 交互式行为流向图" icon="magnifier">
    图形化行为流向图支持关联高亮，鼠标悬停于“行为胶囊”上即可自动点亮资金流向并加速流动，直观解析复杂多方共犯关系。
  </Card>
  
  <Card title="📋 一键无缝复用" icon="document">
    支持一键生成带有完全交互效果的纯净 HTML 源码，或生成自动防止 Obsidian/Notion 强缓存的 iframe 嵌入代码。
  </Card>
  
  <Card title="⚖️ 考点对比记忆矩阵" icon="setting">
    整合司法解释多重截留、代收、隐瞒、猜出等演变模型，通过对比矩阵列出主体罪名差异与罪数处断，杜绝考点混淆。
  </Card>
</CardGrid>
