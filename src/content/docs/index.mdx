## 🚀 核心交互功能

<CardGrid stagger>
  <Card title="🧠 记忆背诵消隐模式" icon="open-book">
    在页面右上角一键开启消隐遮罩，模糊关键定性、数额等结论词，鼠标悬停即可显现，专为法考背诵记忆设计。
  </Card>

  <Card title="🔍 交互式行为流向图" icon="magnifier">
    图形化行为流向图支持关联高亮，鼠标悬停于节点上即可自动点亮关联要素并加速流动，直观解析复杂多方关系。
  </Card>

  <Card title="📋 一键无缝复用" icon="document">
    支持一键生成带有完全交互效果的纯净 HTML 源码，或生成自动防止 Obsidian/Notion 强缓存的 iframe 嵌入代码。
  </Card>

  <Card title="⚖️ 考点对比记忆矩阵" icon="setting">
    以对比矩阵、分流仪、控制台等图形语法并列呈现易混考点，标注主体差异与处断规则，杜绝考点混淆。
  </Card>
</CardGrid>
