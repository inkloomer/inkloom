职务侵占罪的认定需依次满足三个特殊构成要件（B₁＋B₂＋B₃），任一不满足即退回基础罪名（侵占／盗窃／诈骗）。下方流程图展示完整判断路径。

<Mermaid>
flowchart TD
    A["⚖️ 行为人的基础行为 A"] --> B1{"🔍 行为主体是<br/>非国家工作人员？<br/>B₁"}
    B1 -- "❌ 否" --> N1["🚫 不构成职务侵占罪<br/>可能构成贪污罪"]
    B1 -- "✅ 是" --> B2{"📦 行为对象是<br/>本单位财物？<br/>B₂"}
    B2 -- "❌ 否" --> N2["🔄 退回基础罪名<br/>侵占 / 盗窃 / 诈骗"]
    B2 -- "✅ 是" --> B3{"🔑 利用<br/>职务便利？<br/>B₃"}
    B3 -- "❌ 否" --> N3["🔄 退回基础罪名<br/>侵占 / 盗窃 / 诈骗"]
    B3 -- "✅ 是" --> R["⚡ 职务侵占罪成立<br/>= A + B₁ + B₂ + B₃"]

<Aside type="tip" title="公式记忆">
**职务侵占罪** = 基础行为 (A) ＋ 非国家工作人员 (B₁) ＋ 本单位财物 (B₂) ＋ 利用职务便利 (B₃)

三个特殊要件层层递进、缺一不可：主体不符→贪污罪；对象不符或未利用职务便利→退回侵占／盗窃／诈骗基础罪名。
</Aside>
