## 债权问题三类型

行为人与被害人之间的债权债务关系，分为三种类型。

### 类型一：行为人是债务人，被害人是合法债权人

- **骗免过路费案**：甲使用假军车牌骗免过路费 → 收费员放弃行使债权 → 多数说：**诈骗罪**
- **抢劫车费案**（2002年第12题）：王某用刀威胁司机放弃车费 → 多数说：**抢劫罪**（抢劫财产性利益）

<Aside type="tip" title="核心要点 · 「财产性利益」的含义">
- 债权人只是**放弃当场行使债权**，并未在民法上丧失债权
- 损失的是「债权人当场实现债权」的机会
- 债务人获得的是**延迟履行债务**的利益
</Aside>

#### 「转移占有」问题 · 观点展示

| 学说 | 观点 |
| --- | --- |
| 少数说 | 不构成犯罪。要求将他人占有的财物转移为自己占有，本案中不存在债权转移 |
| 多数说 | 「转移占有」是针对有形财物的要求。侵犯财产性利益只需：①他人丧失财产性利益 ②自己获得财产性利益 ③条件关系＋加减关系 |

#### 餐厅逃单案 · 盗窃方式逃避债务

甲开始有付费意思，吃完后偷偷溜走。

| 学说 | 结论 | 理由 |
| --- | --- | --- |
| 多数说 | 不构成盗窃罪 | ① 店家没有放弃行使债权；② 逃单按民事纠纷处理，刑法应保持谦抑性 |
| 少数说 | 构成盗窃罪 | 甲导致店家无法当场行使债权，获得延迟履行债务的利益 |

### 类型二：行为人是债务人，被害人是非法债权人

**骗免嫖资案**：甲用假币支付嫖资 3 千元 → 构成**使用假币罪**。是否构成诈骗罪？

| 学说 | 观点 | 结论 |
| --- | --- | --- |
| 法律的财产说（少数说） | 刑法只保护民法上的合法财产权 | 不构成诈骗罪 |
| 经济的财产说（少数说） | 只要有经济价值的利益，刑法就应保护 | 构成诈骗罪 |
| 法律与经济的财产说（多数说） | 保护法秩序认可的、具有经济价值的利益 | **不构成诈骗罪** |

**欺骗分赃案**：苏某与王某共同抢劫，销赃获 1 万元，谎称仅得 4000 元。多数说不构成诈骗罪，法秩序不认可销赃款请求权。

### 类型三：行为人与被害人没有债权债务关系

- **强迫写欠条案**：甲持刀逼迫乙写下欠条，后未能实现债权 → **抢劫罪（未遂）**
- **非法充值案**：甲以技术手段非法充值会员卡 1 万元并使用 → **盗窃罪（既遂）**

<Aside type="caution" title="行为与行为对象同时存在原则">
类型一、二中，行为人侵犯**已然存在**的债权。类型三中，行为人**为自己生成**非法债权，非法债权属于**行为滋生之物**，不需要遵守该原则。
</Aside>

#### 冒名收款案／偷换二维码案 · 三角关系

犯罪人 → 债务人/受骗人 → 债权人/被害人。**判断被害人**：看债务人是否有效履行债务。若已履行 → 债务人无损失，债权人是被害人。

| 学说 | 结论 | 理由 |
| --- | --- | --- |
| 少数说 | 盗窃罪 | 代为行使债权，盗窃债权（财产性利益） |
| 多数说 | **新型三角诈骗** | 受骗人处分的是**自己的财物**（区别于传统三角诈骗） |

## 存款债权的性质

<Aside type="tip" title="核心理解">
- 储户现金存入银行 → 现金归银行**所有、占有**
- 储户换来 → **针对银行的债权**（存款债权）
- 存款债权已被**实体化**，可自由转移转让
- 分析时使用「占有」及「转移占有」概念
</Aside>

### 卖卡后针对合法资金：掐卡、转账、取款

| 事实占有说（多数说） | 法律占有说（少数说） |
| --- | --- |
| 实质标准：乙在事实上占有该资金 | 形式标准：甲是名义卡主，法律上占有 |
| 🔒 **掐卡** → 盗窃罪 | 掐卡、转账、取款**一体看待** |
| 💸 **转账** → 不再定罪（左口袋→右口袋） | 乙所有、甲占有 → 甲所有 |
| 🏧 **柜台取款** → 多数：对银行构成诈骗罪；少数：不构成 | 构成**侵占罪** |
| 🏧 **ATM 取款** → 多数：对银行构成盗窃罪；少数：不构成 | |

### 卖卡后针对赃款：掐卡、转账、取款

前提：甲知道乙用于电信网络诈骗，卡里多了一万元赃款。

| 学说 | 整体定性 | 说明 |
| --- | --- | --- |
| 事实占有说（多数说） | **整体构成盗窃罪** | 保护乙对赃款的非法占有事实，不允许「黑吃黑」 |
| 法律占有说（少数说） | **整体构成侵占罪** | 甲是法律占有人，将他人所有、自己占有的资金变自己所有 |
| 具体判断说（少数说） | 掐卡、转账：不定罪；取款：分歧 | 掐卡帮助追赃，转账进一步占有，取款多数：对银行构成犯罪；少数：不构成 |

### 错误汇款

乙本想给丙汇款，不慎打到甲卡里。甲占有该资金属于不当得利。

| 甲针对乙 | 甲针对银行（ATM 取现） |
| --- | --- |
| 花掉这笔钱 → **不构成侵占罪**（种类物） | 多数说：构成**盗窃罪**（对象是银行现金） |
| 拒不返还 → **构成侵占罪** | 少数说：不构成（法律占有人，有取款权限） |

## 电力与电费

- **例1 · 偷接电线**：甲在邻居电线上偷接电线供自己使用 → **盗窃电力，构成盗窃罪**
- **例2 · 电表做手脚骗免电费**（2021年试题）：甲在电表上安装非法设备，实际用 5000 度只显示 1000 度 → **诈骗罪**（骗免电费，诈骗财产性利益）。收费员处分行为表现为不作为（不行使权利）
- **例3 · 电卡无余额继续用电**：甲电卡无余额，采取技术手段继续用电 → **盗窃电力，构成盗窃罪**

## 电话、网络（司法解释总结）

| 行为类型 | 定罪 | 数额计算 |
| --- | --- | --- |
| 盗接通信线路、复制电信码号、明知盗接/复制而使用 | 盗窃罪（第265条） | 给他人造成的资费损失 |
| 盗用他人上网账号、密码上网 | 盗窃罪 | 给他人造成的资费损失 |
| 将电信卡非法充值后使用 | 盗窃罪 | 给他人造成的资费损失 |
| 明知是非法充值的电信卡而使用/购买使用 | 盗窃罪 | 给他人造成的资费损失 |
| 以虚假身份证件欺骗电信公司（先使用后交费），不想交费 | 诈骗罪 | 资费损失数额 |

## 有罪情形（多数说）

<Aside type="note" title="核心规则">
对甲**非法占有的财物**，乙非法转移为自己占有 → **乙有罪**。刑法保护甲对财物的非法占有，非法占有能够对抗第三人。
</Aside>

| 类型 | 案例 | 结论 |
| --- | --- | --- |
| 甲非法占有的赃物 | 甲偷到丙的摩托车，乙从甲家偷走 | **乙构成盗窃罪** |
| 甲非法占有的赃款 | 甲诈骗到丙的钱款存存折里，乙非法转移占有 | **乙构成盗窃罪** |
| 共同犯罪中的赃物/赃款 | 甲乙共同盗窃，甲保管占有，乙没有事实占有 | **乙构成盗窃罪**（虽构成帮助犯既遂，但不意味着现实占有犯罪所得） |
| 甲非法占有违禁品 | 甲非法持有毒品，乙从甲家偷走 | **乙构成盗窃罪** |

## 无罪情形（多数说）

<Aside type="note" title="核心规则">
甲没有非法占有财物，甲对财物仅有**非法请求权**，乙侵犯该请求权 → **乙无罪**。刑法不禁止这种「黑吃黑」。
</Aside>

### 第一种类型：甲仅有非法债权

- **骗免嫖资案**：嫖客用假币支付嫖资 → 不构成诈骗罪（法秩序不认可卖淫女非法债权），构成使用假币罪
- **欺骗分赃案**：乙对甲谎称销赃款仅得 4000 元 → 不构成诈骗罪（法秩序不认可甲对销赃款请求权）

### 第二种类型：基于不法原因的委托物

| 情形 | 案例 | 结论 |
| --- | --- | --- |
| 委托给付的财物 | 甲委托乙向官员行贿，乙据为己有 | **不构成侵占罪**（甲的返还请求权非法） |
| 委托保管的财物（告知是赃物） | 甲将盗窃的摩托车委托乙保管，乙拒不返还 | **不构成侵占罪**，构成掩饰、隐瞒犯罪所得罪 |
| 委托保管的财物（合法原因） | 甲将盗窃的摩托车交乙修理，乙察觉后拒不归还 | **构成侵占罪**（甲基于合法原因委托） |
